# 全季阶段大纲（season-outline）

## 阶段结构总览

### 阶段一：弃婴与断亲爆发（1-8）

- 主要事件：雪夜救婴、卫生所收养、老宅冲突、断亲分家、命名苏沅禾。
- 核心冲突：三房生存权 vs 老宅控制权。
- 情绪走向：悲痛压抑 → 愤怒爆发 → 规则重建。
- 人物成长：苏建业从隐忍到站队，林晚枝从悲痛到主导。
- 爽点：当众断亲、签字按手印。
- 阶段结尾：丫丫正式成为三房家庭成员。

### 阶段二：求生开局与第一桶金（9-27）

- 主要事件：搬新居、上山采药、发现并售出老山参。
- 核心冲突：贫困生存压力 vs 机会获取与风险。
- 情绪走向：焦虑 → 希望 → 狂喜。
- 人物成长：三房形成“家庭协作体”。
- 爽点：六十年野山参高价交易。
- 阶段结尾：资金与票证到手，进入稳盘期。

### 阶段三：资源暴露后的围攻与反制（28-48）

- 主要事件：村口流言、老宅觊觎、偷盗冲突、回娘家补位。
- 核心冲突：边界防守 vs 家族道德绑架。
- 情绪走向：警惕 → 对抗 → 回温。
- 人物成长：三房边界意识与社交支持网增强。
- 爽点：当场抓包、公开反击。
- 阶段结尾：家庭关系重新稳固。

### 阶段四：三年后与新危机潜伏（49-61）

- 主要事件：时间跳转到1973、大旱背景、儿童线冲突、苏春妮重生视角揭露。
- 核心冲突：集体匮乏下的生存竞争 + 针对丫丫的隐性恶意。
- 情绪走向：日常热闹 → 阴影逼近。
- 人物成长：丫丫从“被护”走向“可行动角色”。
- 爽点：正面回怼老宅逻辑。
- 阶段结尾：针对丫丫的阴谋明确化。

### 阶段五：人贩线高压营救（62-77）

- 主要事件：诱骗离家、山洞被困、犬只助救、全村搜山、公安介入。
- 核心冲突：儿童安全 vs 有组织犯罪。
- 情绪走向：惊悚 → 追救 → 释压。
- 人物成长：三房与村社协作能力显著提升。
- 爽点：人贩落网、恶意者被公开追责。
- 阶段结尾：危机暂解，余波仍在。

### 阶段六：互助回流与救荒能力显现（78-98）

- 主要事件：儿童群像修复、奖励争议、钓鱼换粮规模化。
- 核心冲突：家庭资源 vs 大队集体生存。
- 情绪走向：修复 → 振奋 → 集体希望。
- 人物成长：丫丫叙事功能从家内核心扩展到公共价值。
- 爽点：鱼获换粮、大队见证“有救了”。
- 阶段结尾：老宅再起算计。

### 阶段七：孝道绑架回潮（99-100）

- 主要事件：老宅密谋装病，上门索取，断亲责任再辩。
- 核心冲突：情感原谅 vs 责任边界。
- 情绪走向：试探 → 纠缠 → 争议悬停。
- 人物成长：苏建业明确“原谅不等于复归供养责任”。
- 爽点：现场说理，守住断亲边界。
- 阶段结尾：冲突未终局，留后续延展空间。
