# 《被调换后，我在北大荒杀疯了》AI 漫剧知识库

## 项目定位

- 本仓库用于《被调换后，我在北大荒杀疯了》AI 漫剧分析、改编与创作协作。
- 唯一剧本事实来源为：`scripts/被调换后，我在北大荒杀疯了 100集-编剧王中辉 (1).txt`。
- 当前已按完整 100 集剧本建立结构化知识库文件夹。

## 目录说明

- `00_project/`：项目总览、创作方向、连续性检查规则。
- `01_world/`：时代背景、地点体系、时间线。
- `02_characters/`：角色总表、主角、对立角色、配角。
- `03_story/`：全季阶段结构与 1-100 集单集大纲。
- `04_scripts/`：原始剧本索引与使用说明。
- `05_prompts/`：AI 画面与声音生成提示词规则库。
- `06_storyboards/`：单集分镜复用模板。

## AI 协作规则

- 先读取设定：改写或新增内容前，先读 `00_project`、`01_world`、`02_characters`。
- 保持连续：人物年龄、称谓、关系、事件先后必须与已确认事实一致。
- 冲突先标记：若出现文本矛盾，先写入“待确认”，不得私自修正为单一版本。
- 不擅改事实：不得擅自改写已确定剧情、人物关系与关键节点。
