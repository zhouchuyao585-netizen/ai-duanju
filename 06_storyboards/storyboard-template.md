# 单集分镜模板（storyboard-template）

## 使用说明

- 每个镜头一行，按时间顺序填写。
- 中文 Prompt / English Prompt / Negative Prompt 必填。
- 连续性检查项需逐镜核对人物年龄、服装、道具与时间线。

## 连续性检查清单（每集收尾）

- [ ] 人物姓名/称呼与角色库一致。
- [ ] 年龄段与服装匹配当前时间线。
- [ ] 地点、道具、光线与既有设定一致。
- [ ] 冲突事件与前后集因果连贯。
- [ ] 无现代穿帮与错误字幕/水印。

## 资料来源
